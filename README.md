# CitaGo

Monorepo de CitaGo.

| Carpeta    | Descripción                  | Stack           |
| ---------- | ---------------------------- | --------------- |
| `citago/`  | Backend (API)                | NestJS + pnpm   |
| `citagof/` | App móvil                    | Flutter         |

## Backend

```bash
cd citago
pnpm install
pnpm start:dev
```

## App

```bash
cd citagof
flutter pub get
flutter run
```
