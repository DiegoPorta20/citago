# Testing Skill

Every use case must have tests.

Prioritize:

1. Domain tests
2. Use case tests
3. Integration tests
4. Controller tests
5. End-to-end tests

Critical business scenarios:

- Create appointment
- Prevent appointment overlap
- Cancel appointment
- Complete appointment
- Create sale
- Calculate daily revenue
- Create client from WhatsApp message
- Process duplicate webhook
- Isolate tenants
